# Lesson plan builder

Design a session people actually learn from.

## When to use
The user has a topic and an audience and needs a plan for a class, workshop or onboarding session.

## Inputs to collect
- Audience and what they already know.
- Session length and format (online, in person, self-paced).
- The one thing learners must be able to do at the end.

## Steps
1. Write 2 to 4 objectives that start with an observable verb (explain, build, compare, fix).
2. Split the time: opening (10%), teaching in short blocks, practice (at least 40%), wrap-up.
3. For each block write the activity, what the instructor does, what learners do and the minutes.
4. Add a practice task that uses a realistic example and has a clear result to check.
5. Write a 5-question check that tests the objectives, with answers and a one-line explanation each.
6. List materials and preparation.

## Output format
`Objectives`, `Agenda` (table with time, activity, instructor, learners), `Practice task`, `Check questions`, `Materials`.

## Quality checks
- Every objective is covered by a practice step and a check question.
- The total time adds up to the session length.
