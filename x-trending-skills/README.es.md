## Fórmula de popularidad

```
popularidad = 10·ln(1+E) + 8·ln(1+N) + 3·log10(1+S); E = me gusta + 2·reposts + 3·citas + respuestas + guardados, sumados sobre los posts de X muestreados distintos que mencionan la skill en los últimos 7 días; N = número de esos posts; S = estrellas de GitHub (0 si se desconoce). Popularidad de una categoría = suma de la de sus skills. x_posts_7d (recuento reciente de X, solo para las N primeras skills) se muestra aparte y no entra en la fórmula.
```

- Referencias = posts de X que mencionan la skill y su interacción; indicador de uso = estrellas y forks de GitHub.
- Los valores desconocidos se muestran como «—», nunca como 0.
- Un post que cita varias skills cuenta por completo para cada una.
- Los posts son una muestra de la búsqueda de X (40 llamadas como máximo por ejecución), no un censo.
- Los nombres de productos y repositorios no se traducen.
