## Formule de popularité

```
popularité = 10·ln(1+E) + 8·ln(1+N) + 3·log10(1+S) ; E = j'aime + 2·reposts + 3·citations + réponses + signets, cumulés sur les posts X échantillonnés distincts qui mentionnent le skill sur 7 jours glissants ; N = nombre de ces posts ; S = étoiles GitHub (0 si inconnu). Popularité d'une catégorie = somme de celle de ses skills. x_posts_7d (comptage X récent, pour les N premiers skills seulement) est indiqué à part et n'entre pas dans la formule.
```

- Références = posts X qui mentionnent le skill et leur engagement ; indicateur d'usage = étoiles et forks GitHub.
- Les valeurs inconnues sont affichées « — », jamais 0.
- Un post qui cite plusieurs skills compte entièrement pour chacun d'eux.
- Les posts sont un échantillon de la recherche X (40 appels maximum par exécution), pas un recensement.
- Les noms de produits et de dépôts ne sont pas traduits.
