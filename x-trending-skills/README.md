## Heat formula

```
heat = 10*ln(1+E) + 8*ln(1+N) + 3*log10(1+S); E = likes + 2*reposts + 3*quotes + replies + bookmarks summed over distinct sampled X posts mentioning the skill in the trailing 7 days; N = number of those posts; S = GitHub stars (0 if unknown). Category heat = sum of skill heat. x_posts_7d (X recent-count for the top skills' queries) is reported separately and not in heat, because it is only fetched for the top-N skills.
```

- References = X posts mentioning the skill and their engagement; usage proxy = GitHub stars/forks.
- Unknown values are shown as “—”, never 0.
- A post that lists several skills counts fully toward each of them.
- Posts are a sample from X search (at most 40 calls per run), not a census.
- Product and repository names are kept untranslated.

## Layout

- `categories/<category>.md` — skills per category (English); `categories/fr|es|zh/` for other languages
- `data/skills.json` — latest snapshot (all four languages)
- `data/snapshots/YYYY-MM-DD.json` — daily snapshots
- Databricks table: `lab.lab.skill` (one row per skill per day)
