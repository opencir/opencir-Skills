## 热度公式

```
热度 = 10·ln(1+E) + 8·ln(1+N) + 3·log10(1+S)；E = 点赞 + 2×转发 + 3×引用 + 回复 + 收藏，按最近 7 天提及该技能的不重复样本帖子求和；N = 这些帖子数；S = GitHub stars（未知记 0）。分类热度 = 该类技能热度之和。x_posts_7d（X 近期计数，仅对前 N 个技能查询）单独展示，不计入热度。
```

- 被引用量 = X 上提及该技能的帖子及其互动量；被使用量参考 GitHub stars/forks。
- 未知数据显示为 “—”，不是 0。
- 一条帖子提到多个技能时，其互动量会完整计入每个技能。
- 帖子来自 X 搜索的样本（每次最多 40 次调用），不是全量统计。
- 产品名和仓库名保持原文，不翻译。
