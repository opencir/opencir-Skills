## Fórmula de calor

```
calor = 10·ln(1+E) + 8·ln(1+N) + 3·log10(1+S) + 2·log10(1+I); E = me gusta + 2×reposts + 3×citas + respuestas + guardados, sumados sobre la muestra anual de posts de X del skill (búsqueda en archivo completo 2025-11-12 → 2026-11-12, 25 primeros por relevancia, sin retuits); N = posts de la muestra (máx. 25); S = estrellas de GitHub (0 si se desconoce); I = instalaciones totales en skills.sh del repo (0 si se desconoce o si es sospechoso: instalaciones > 1000 × estrellas). Calor del sector = suma del de sus skills; sectores y skills ordenados por calor.
```

## Notas y limitaciones

- No hay total anual de menciones en X (el conteo de X usado cubre solo 7 días): x_yearly_mentions es NULL; N es una muestra por relevancia limitada a 25 posts.
- Las consultas amplias (plugins legales/RR. HH., Stripe, Shopify, Firecrawl) pueden incluir posts poco relacionados, y una lista que cita varios skills cuenta para cada uno; la interacción es un indicador, no un conteo exacto.
- Las instalaciones de skills.sh las declara la plataforma; si superan 1000× las estrellas de GitHub se marcan y se excluyen del calor.
- Estrellas/forks de GitHub leídos el 2026-11-12 con la API pública. El calor acumulado favorece a sectores con más skills; también se muestra el calor medio por skill.

⚠ = marcado como posiblemente inflado, excluido del calor
