## Heat formula

```
heat = 10*ln(1+E) + 8*ln(1+N) + 3*log10(1+S) + 2*log10(1+I); E = likes + 2*reposts + 3*quotes + replies + bookmarks summed over the year sample of X posts for the skill (full-archive search 2025-11-12 → 2026-11-12, top 25 by relevancy, retweets excluded); N = posts in that sample (max 25); S = GitHub stars (0 if unknown); I = skills.sh total installs for the repo (0 if unknown, and 0 if flagged suspicious: installs > 1000 x stars). Industry heat = sum of its skills' heat; industries and skills ranked by heat.
```

## Notes & limitations

- X yearly mention totals are not available (the X counts endpoint used here covers only the last 7 days), so x_yearly_mentions is NULL; N is a relevancy sample capped at 25 posts.
- Broad queries (e.g. legal/HR plugins, Stripe, Shopify, Firecrawl) can include loosely related posts, and list posts that cite many skills count for each skill they cite; treat engagement as an indicator, not an exact count.
- skills.sh installs are self-reported by the marketplace; values > 1000× GitHub stars are flagged and excluded from heat.
- GitHub stars/forks were read on 2026-11-12 from the public GitHub API. Industry heat favours industries with more catalogued skills; the average heat per skill is also shown.

⚠ = flagged as possibly inflated, excluded from heat
