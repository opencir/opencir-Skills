## 热度公式

```
热度 = 10·ln(1+E) + 8·ln(1+N) + 3·log10(1+S) + 2·log10(1+I)；E = 该技能年度 X 样本帖子的 点赞 + 2×转发 + 3×引用 + 回复 + 收藏 之和（全量归档搜索 2025-11-12 → 2026-11-12，按相关度取前 25 条，不含转推）；N = 样本帖子数（最多 25）；S = GitHub 星标（未知记 0）；I = skills.sh 仓库总安装量（未知记 0；安装量 > 1000×星标 视为可疑，记 0 不计入热度）。行业热度 = 行业内技能热度之和；行业与技能均按热度排序。
```

## 说明与局限

- 无法获得 X 年度提及总量（所用计数接口只覆盖最近 7 天），因此 x_yearly_mentions 为 NULL；N 是按相关度抽取、上限 25 条的样本。
- 宽泛查询（如法律/HR 插件、Stripe、Shopify、Firecrawl）可能混入弱相关帖子；列举多个技能的清单帖会分别计入每个被提及的技能；互动量仅作热度参考，并非精确计数。
- skills.sh 安装量由平台自报；超过 GitHub 星标 1000 倍的会被标记并不计入热度。
- GitHub 星标/分叉于 2026-11-12 通过公开 API 读取。行业热度为求和，技能多的行业占优；同时给出行业平均热度。

⚠ = 疑似刷量，未计入热度
